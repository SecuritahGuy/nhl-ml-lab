# NHL ML Lab — Agents Guide

## Project Overview

NHL game outcome prediction with MLX (Apple Silicon GPU) training + Cloudflare Pages deployment.

- **Python backend**: FastAPI (`backend/`) — feature engineering, model training, live prediction API
- **Website**: Next.js 14 static export + Cloudflare Pages Functions (`website/`)
- **Model training**: MLX on Apple Silicon (`backend/app/models/train_mlx.py`)
- **Edge inference**: Logistic regression weights exported to TypeScript, run in Pages Functions

## Cross-Cutting Changes

When adding a **new feature**, you must update ALL of these files with the same logic:

| Layer | File | Change |
|-------|------|--------|
| Training (Python) | `backend/app/models/train.py` | Add to `engineer_features()` and `_make_features()` |
| Live API (Python) | `backend/app/models/predictor.py` | Add to `predict_game()` and `_build_rolling()` |
| Edge inference (TS) | `website/functions/_features.ts` | Add to `buildFeatureVector()` and `buildRollingArray()` |
| Edge model weights | `website/functions/_model.ts` | Auto-generated by `train_mlx.py` export |
| Rolling constants | `ROLLING_WINDOWS`, `DECAY_FACTORS`, `ROLLING_SUFFIXES` | Must match across all files |

### Feature ordering is critical

Rolling features must appear in the **same exact order** in both Python and TypeScript.
Python groups by stat type then window: `[all gf_roll, all ga_roll, all gd_roll, all win_roll, all gf_decay, ...]`
TypeScript must match. When changing `ROLLING_SUFFIXES`, update `buildRollingArray()` in `_features.ts` to match.

### Feature count

- Base + context + player: 52 features (16 team-season, 9 differentials, 6 game context, 8 player, 4 team-advanced, 5 rest/day)
- Rolling per team: 29 features (4 gf_roll + 4 ga_roll + 4 gd_roll + 4 win_roll + 3 gf_decay + 3 ga_decay + 3 gd_decay + 3 win_decay + 1 rest_days)
- **Total: 52 + 29×2 = 110 features**

## Common Tasks with Sub-Agents

### Retrain model + deploy to website
```
1. Run: source .venv/bin/activate && python3 backend/app/models/train_mlx.py
2. cp backend/models/mlx_model.ts website/functions/_model.ts
3. cd website && npm run build
```

### Add a new feature
Use the `add-feature` sub-agent which handles all cross-cutting edits in parallel.
Or manually: edit `train.py` → `predictor.py` → `_features.ts` in that order,
ensuring the feature name, position, and fallback logic match.

### Deploy to Cloudflare Pages
```
cd website && npm run build && npx wrangler pages deploy out --project-name nhl-ml-lab
```

## Sub-Agents

Use `task` tool with `subagent_type: "general"` for complex multi-file edits.
Use `task` with `subagent_type: "explore"` for codebase searches.
Define reusable agents in `.opencode/agent/<name>.md`.
